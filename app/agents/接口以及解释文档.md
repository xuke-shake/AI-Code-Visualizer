

#  Agent 模块核心接口手册

## 1. 核心数据结构 (Data Models)

其他开发调用接口后，会拿到这个标准结构体。

```python
@dataclass
class AgentResult:
    mermaid_code: str      # 最终生成的标准 Mermaid 文本（前端直接拿去渲染）
    node_mapping: dict      # 图表节点与物理源码的映射关系（目前为结构占位）
    agent_logs: list[dict]  # 流水线日志，包含每一步的耗时和错误，格式见下文

```

### `agent_logs` 每一项的标准 JSON 格式：

```json
{
  "agent_name": "DiagramAgent", // 智能体名称
  "input_summary": "...",       // 输入数据摘要
  "output_summary": "...",      // 输出数据摘要
  "duration_sec": 1.234,        // 该步骤精准耗时（秒）
  "errors": null                // 报错信息。如果成功为 null，失败则是字符串
}

```
